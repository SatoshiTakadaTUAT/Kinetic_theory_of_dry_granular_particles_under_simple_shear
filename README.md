# Kinetic theory of sheared granular particles

Julia code and plotting scripts for studying the steady rheology of dense granular flows under simple shear and comparing kinetic-theory predictions with particle simulation results.

The collisional moments and collisional stresses are evaluated using generalized hypergeometric functions, without finite-order truncation in the expansion parameter ε = 1/√θ.

## Files

| File | Description |
|---|---|
| `main.jl` | Runs parameter sweeps and saves steady-state rheological quantities. |
| `hypergeometric.jl` | Defines the radial distribution function, generalized hypergeometric functions, auxiliary functions, collisional moments, and collisional stresses. |
| `time_evol.jl` | Evolves the moment equations from a Bagnold initial condition to obtain steady states. |
| `rheology.jl` | Calculates viscosity, normal stress differences, stress ratio, and stress orientation. |
| `coeff.txt` | Particle simulation results used for comparison with the theory. |
| `Fig.plt` | Generates EPS figures comparing the present theory with simulations, including ratios to the Garzó–Dufty reference implemented in the script. |
| `comp_w_SA.plt` | Generates EPS figures comparing the present theory, Saha–Alam theory, and simulations. |
| `N_dependence.plt` | Compares simulation data for particle numbers N = 1000 and 4000 at φ = 0.30. Here N denotes particle number, not series truncation order. |

Use the filenames shown above. If downloaded copies are named `main(1).jl`, `hypergeometric(1).jl`, or `time_evol(1).jl`, rename them to remove `(1)` before running. Keep the Julia files in the same directory.

## Requirements

- Julia with `HypergeometricFunctions` and `SpecialFunctions`.
- Gnuplot with PostScript/EPS support for plotting.
- `Printf` is part of the Julia standard library.

Install the Julia packages once:

```sh
julia -e 'using Pkg; Pkg.add(["HypergeometricFunctions", "SpecialFunctions"])'
```

The supplied `hypergeometric.jl` also calls `Pkg.add("HypergeometricFunctions")` when loaded. After installing the dependencies, this installation line may be removed to avoid running package management each time.

## Running the theory calculations

From the directory containing the code, run:

```sh
julia main.jl
```

Two sweeps are defined in `main.jl`:

| Function | Varied parameter | Fixed parameter | Output |
|---|---|---|---|
| `run1(phi_list1, e_list1)` | Volume fraction φ | Restitution coefficient e | `e_0.70.txt`, etc. |
| `run2(phi_list2, e_list2)` | Restitution coefficient e | Volume fraction φ | `phi_0.40.txt`, etc. |

The supplied settings are:

```julia
phi_list1 = LinRange(0.01, 0.5, 50)
e_list1 = [0.70, 0.80, 0.90, 0.95]

phi_list2 = [0.40]
e_list2 = LinRange(0, 0.99, 100)
```

To generate all fixed-φ theory files required by `Fig.plt` and `comp_w_SA.plt`, use:

```julia
phi_list2 = [0.01, 0.10, 0.30, 0.40, 0.45]
```

Output filenames use two decimal places. Existing files with the same names are overwritten. The Bagnold initial condition is singular at e = 1, so exclude this endpoint.

### Steady-state calculation

`cal_evol(phi, e)` evolves θ, Δθ, δθ, and the normalized kinetic shear stress using an explicit Euler update with a step size determined by the largest absolute right-hand side. Every 10,000 steps, the code checks the relative change in θ against `threshold = 1e-10`.

This stopping criterion checks temperature convergence; it does not independently impose a tolerance on every moment-equation residual. The supplied loop has no maximum iteration count.

## Theory output format

The theory output files contain seven whitespace-separated columns without a header:

| Column | `e_*.txt` | `phi_*.txt` |
|---|---|---|
| 1 | Volume fraction φ | Restitution coefficient e |
| 2 | Dimensionless temperature θ | Dimensionless temperature θ |
| 3 | Dimensionless viscosity η* | Dimensionless viscosity η* |
| 4 | First normal stress difference N₁ | First normal stress difference N₁ |
| 5 | Second normal stress difference N₂ | Second normal stress difference N₂ |
| 6 | Stress ratio μ | Stress ratio μ |
| 7 | Stress orientation angle, in radians | Stress orientation angle, in radians |

With P the total pressure tensor and p = tr(P)/3, the normal stress differences and stress ratio are

$$
N_1 = \frac{P_{xx}-P_{yy}}{p},\qquad
N_2 = \frac{P_{yy}-P_{zz}}{p},\qquad
\mu = -\frac{P_{xy}}{p}.
$$

The stored angle follows `cal_angle` in `rheology.jl`. `Fig.plt` subtracts π/4 when plotting it.

## Particle simulation data

`coeff.txt` contains particle simulation results; it is an input dataset and is not generated by the Julia code.

The plotting scripts use the following 12-column format:

| Column | Quantity |
|---|---|
| 1 | Volume fraction φ |
| 2 | Restitution coefficient e |
| 3 | Dimensionless temperature θ |
| 4 | Temperature uncertainty used for error bars |
| 5 | Shear stress Pxy in the simulation data normalization |
| 6 | Shear stress uncertainty used for error bars |
| 7 | Pressure in the simulation data normalization |
| 8 | Pressure uncertainty |
| 9 | N₁ |
| 10 | N₁ uncertainty used for error bars |
| 11 | N₂ |
| 12 | N₂ uncertainty used for error bars |

The plotting scripts convert column 5 to viscosity using `-column5/dens(phi)`, where `dens(phi) = 6*phi/pi`. They calculate μ as `-column5/column7`. The statistical interpretation of the uncertainty columns should follow the simulation analysis used to prepare the dataset.

## Plotting

Run the plotting scripts from the directory containing their input data:

```sh
gnuplot Fig.plt
gnuplot comp_w_SA.plt
gnuplot N_dependence.plt
```

Each script writes EPS files to the current directory. Axis labels are left blank in the supplied scripts and can be set with `set xlabel` and `set ylabel`.

| Script | Required data |
|---|---|
| `Fig.plt` | `coeff.txt`; `e_0.70.txt`, `e_0.80.txt`, `e_0.90.txt`, `e_0.95.txt`; `phi_0.01.txt`, `phi_0.10.txt`, `phi_0.30.txt`, `phi_0.45.txt`. |
| `comp_w_SA.plt` | `coeff.txt`; present-theory and corresponding `_SA.txt` files for e = 0.70, 0.90 and φ = 0.10, 0.40. |
| `N_dependence.plt` | `phi_0.30.txt`, `coeff.txt`, and `coeff_4000.txt`. The script labels the two simulation datasets as N = 1000 and N = 4000, respectively. |

The supplied Julia code generates the present-theory data only. The Saha–Alam comparison files and `coeff_4000.txt` must be supplied separately to run the corresponding plots.

### Saha–Alam data format

The `_SA.txt` files use a separate nine-column format:

| Column | Quantity |
|---|---|
| 1 | Varied parameter: φ for `e_*_SA.txt`, or e for `phi_*_SA.txt` |
| 2 | θ |
| 3 | Δθ |
| 4 | δθ |
| 5 | Kinetic shear stress contribution |
| 6 | Trace of the collisional stress contribution |
| 7 | Collisional xx stress contribution |
| 8 | Collisional yy stress contribution |
| 9 | Collisional xy stress contribution |

For a row with entries c₁, …, c₉, `comp_w_SA.plt` uses

$$
\eta^* = -(c_5+c_9),\qquad
N_1 = \frac{c_3+c_7-c_8}{c_2+c_6/3},\qquad
N_2 = \frac{c_4-c_3+c_7+2c_8-c_6}{c_2+c_6/3}.
$$

The temperature and viscosity comparison figures in `comp_w_SA.plt` show ratios to the Garzó–Dufty reference functions defined in the script.
